## Upload these

| File | Size | Where in CWS |
| --- | --- | --- |
| `icon-128.png` | 128×128 | Icono de Chrome Web Store |
| `screenshot-1-settings.png` | 1280×800 | Capturas de pantalla |
| `screenshot-2-dropdown.png` | 1280×800 | Capturas de pantalla |
| `promo-small-440x280.png` | 440×280 | Mosaico promocional pequeño (optional) |

Regenerate icons or store assets:

```bash
bun run icons
bun run store-assets
```

Place raw crops as `source/popup.png` and `source/dropdown.png`.
